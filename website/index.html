Ultra-light Windows recorder

纯本地屏幕录制与截图。不上传、不绑架云账号。开箱即用的 NVENC / QSV / AMF，也有可靠的软件编码兜底。

为什么选 Capto

Why Capto

六件事说清楚：Windows 特调、MP4/GIF、Overlay、自研 FFmpeg、面向 AI 的 CLI/Skill、开源本地安全。

Six pillars: Windows-tuned capture, MP4/GIF, overlays, rebuilt FFmpeg, AI-ready CLI/Skill, open source and local-only.

  • 模式 + Windows 特调 — 显示器 / 窗口 / 区域；Windows 优先采集与音频路径
  • MP4 与 GIF — 自动硬件编码（NVENC / QSV / AMF）或 libx264
  • Overlay — 点击高亮、按键显示、摄像头画中画、光标与预览
  • 自研 FFmpeg（capto-ffmpeg） — 钉死版本、可验证侧车；编码只走捆绑二进制，不碰 PATH
  • CLI + Skill，面向 AI — 完备 JSON 控制面与 capto-agent-skill
  • 开源 · 本地 · 安全 — MIT；无上传；文件留在本机
  • Modes + Windows-tuned — Display / window / region; Windows-first capture & audio
  • MP4 & GIF — Auto hardware encode (NVENC / QSV / AMF) or libx264
  • Overlays — Click highlights, keystrokes, webcam PiP, cursor & preview
  • Rebuilt FFmpeg (capto-ffmpeg) — Pinned, attested sidecar; encode only via the bundle, never PATH
  • CLI + Skill for AI — Full JSON control plane and capto-agent-skill
  • Open source · local · safe — MIT; no upload; files stay on disk

Download

从 GitHub Releases 获取 x64 / arm64 的 NSIS 安装包。安装包内嵌经验证的 FFmpeg（capto-ffmpeg）以及 CLI：<安装目录>\cli\capto.exe；安装时写入用户 PATH，新开终端即可用 capto。

Grab the NSIS setup for x64 / arm64 from GitHub Releases. Installers embed verified FFmpeg (capto-ffmpeg) and the CLI at <install>\cli\capto.exe, and add that folder to your user PATH so capto works in new terminals.
